# 💬 ChatApp — Real-Time Private Chat

A modern real-time messaging application designed for private conversations, with instant messaging and a clean, responsive interface.

🌐 **Live Demo:** https://chatapp-itvp.onrender.com

## ✨ Features

- 🔒 Private chat rooms
- 🔗 Shareable room invite links
- 💬 Real-time messaging
- 📸 Photo sharing
- 👀 View-once photo feature
- ⌨️ Typing indicators
- 🔄 Automatic SignalR reconnection
- 📱 Responsive user interface
- 🗄️ Database-backed message persistence

*Feature availability depends on the current implementation and deployment configuration.*

## 🛠️ Tech Stack

- **C# / .NET** — Application development
- **Blazor** — Web user interface
- **ASP.NET Core** — Web application hosting
- **SignalR** — Real-time communication
- **SQL database** — Message persistence
- **HTML, CSS and JavaScript** — Interface and interactions
- **Docker** — Containerized deployment support

## 💻 Run Locally

1. Install the .NET SDK compatible with the project.
2. Clone or download this repository.
3. Open a terminal in the web project directory.
4. Restore dependencies and run the application:

```bash
dotnet restore
dotnet run
```

Open the local URL displayed in your terminal.

## 🔐 Security

- Never commit passwords, API keys, or database credentials.
- Configure production secrets through environment variables or your hosting provider's secret settings.
- Use HTTPS and appropriate authentication and authorization controls for production deployments.
